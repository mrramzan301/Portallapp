# OTP API - Async with 5-Second Delay

Non-blocking OTP API with count parameter.

## Endpoint
`/api/otp`

## Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| number | string | Phone number (10 digits, e.g., 3376313363) |
| count | integer | Number of attempts (max 10, default 1) |
